# Zadanie 12: Gdzie jestem? – nawigacja po folderach przez rozmowę

Ćwiczenie do szkolenia „Wykorzystanie systemu AI Claude we współpracy z
Excel, PowerPoint oraz automatyzacja zadań" (Urząd Miejski w Opolu, Dzień 1,
**Blok D, 60 min: Claude Code – pierwszy kontakt**).

**Cel:** poruszać się po folderach słowami zamiast Eksploratorem.
**Poziom:** podstawowy
**Czas:** ok. 5 minut

> Tu zaczyna się druga część Bloku D: **nawigacja w Windows z AI**.

## Materiały

- Folder `test-claude-code` (po zadaniu 11): pliki `UM_*.xlsx` w folderze
  głównym, w `archiwum/` lipiec i sierpień.

## Kroki

1. ```
   W jakim folderze teraz jesteśmy i co jest w środku?
   ```

2. ```
   Jakie podfoldery są w tym folderze?
   ```

   **Sprawdź:** jeden – `archiwum`.

3. ```
   Pokaż mi, co jest w folderze archiwum.
   ```

   **Sprawdź:** `zestawienie_sierpien.xlsx` i `zal_3_korekta.xlsx`.

4. Zbiorczo:

   ```
   Zrób mi krótkie zestawienie: jakie foldery są w test-claude-code
   i ile plików jest w każdym z nich.
   ```

5. Bez dokładnej nazwy:

   ```
   Który plik zawiera dane za sierpień?
   ```

   **Sprawdź:** Claude wskazuje `archiwum/zestawienie_sierpien.xlsx`.

## Na co zwrócić uwagę

- To samo, co klikanie w Eksploratorze – tylko opisane słowami.
- **Nie trzeba pamiętać nazw** – wystarczy opisać folder lub plik
  w przybliżeniu.
- Od „rozejrzenia się" zaczyna się porządkowanie i szukanie (zad. 13–15).
