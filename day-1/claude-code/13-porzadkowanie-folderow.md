# Zadanie 13: Porządkowanie plików – tworzenie folderów i segregacja

Ćwiczenie do szkolenia „Wykorzystanie systemu AI Claude we współpracy z
Excel, PowerPoint oraz automatyzacja zadań" (Urząd Miejski w Opolu, Dzień 1,
**Blok D, 60 min: Claude Code – pierwszy kontakt**).

**Cel:** poprosić Claude Code o zrobienie porządku w folderze pełnym
pomieszanych plików – klasyczne, żmudne zadanie, które nagle staje się
jednym poleceniem.
**Poziom:** podstawowy
**Czas:** ok. 7 minut

## Materiały

- Folder `test-claude-code` na Pulpicie (kopia
  `../materialy/test-claude-code/`) – w folderze głównym leżą „na kupie"
  4 pliki `.xlsx` z września i października (po zad. 11 z prefiksem
  `UM_`); `archiwum/` zostawiamy bez zmian.

## Kroki

1. Poproście o rozpoznanie bałaganu: *„Zobacz, jakie pliki są w tym
   folderze i zaproponuj, jak sensownie je pogrupować."*
2. Wysłuchajcie propozycji Claude Code (np. „po miesiącu" albo „po
   wydziale") – **to Wy decydujecie**, która logika porządkowania ma
   sens w Waszej pracy.
3. Zatwierdźcie kierunek i poproście o wykonanie, np.: *„Utwórz foldery
   Wrzesien i Pazdziernik i przenieś do nich odpowiednie pliki na
   podstawie nazwy/daty."*
4. Zanim cokolwiek się przeniesie, Claude Code pokaże plan (który plik,
   do którego folderu) – dopiero po zgodzie wykonuje przenoszenie.
5. Sprawdźcie efekt w Eksploratorze plików.

## Na co zwrócić uwagę

- Claude Code **proponuje**, ale to człowiek decyduje o logice
  porządkowania – to nie jest automat działający „po swojemu".
- To samo polecenie zadziała identycznie przy 8 plikach i przy 800 –
  różnica jest tylko w tym, ile czasu zaoszczędzicie.
- To bezpośredni most do Dnia 2: tak samo będziecie prosić Claude Code o
  pracę na realnych (zanonimizowanych) zestawieniach miesięcznych.
