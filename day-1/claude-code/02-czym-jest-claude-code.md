**Poziom:** podstawowy

## Claude Code w trzech zdaniach

Claude Code **pracuje bezpośrednio na plikach w folderze na Twoim
komputerze** – czyta je, poprawia, tworzy nowe, uruchamia polecenia.
Powstał dla programistów (stąd nazwa i terminal), ale rozmawia się z nim
**zwykłym polskim językiem**, dokładnie jak w czacie. Różnica jest w tym,
**co może zrobić**, nie w tym, **jak** się z nim rozmawia.

**Analogia:** Claude Czat to mail z załącznikiem i odpowiedź z nowym
załącznikiem – Ty nosisz pliki tam i z powrotem. Claude Code to ktoś, kto
siada przy Twoim komputerze, otwiera wskazany folder i pracuje w nim.

## Trzy narzędzia obok siebie

| | Claude Czat (Blok C) | Cowork (zadanie 1) | Claude Code (Blok D, Dzień 2) |
|---|---|---|---|
| Gdzie | przeglądarka, claude.ai | aplikacja Claude, klikane | terminal lub aplikacja, w konkretnym folderze |
| Pliki | ręcznie wgrywasz i pobierasz | pracuje w wskazanym folderze | pracuje bezpośrednio w folderze na dysku |
| Kto prowadzi | Ty, krok po kroku | podajesz cel, Claude planuje | podajesz cel, Claude planuje i pokazuje każdy krok |
| Uruchamia polecenia | nie | tak, w tle | tak, z pytaniem o zgodę |

Cowork i Claude Code to ten sam mechanizm w dwóch opakowaniach: Cowork
jest łatwiejszy na start, Claude Code daje pełną kontrolę nad plikami
i poleceniami. Claude Code wymaga min. planu Pro – Urząd ma Team.

## Kroki

1. **Zajrzyj do agendy** (`../../agenda/Agenda_szkolenia.md`) – sprawdź,
   co jest zaplanowane na Blok D Dnia 1 i na Dzień 2.
2. **Zobacz Claude Code na żywo.** Poproś prowadzącego (albo otwórz sam,
   jeśli masz już zainstalowany – zadanie 6) i wpisz pierwsze zdanie:

   ```
   Cześć! W jakim folderze teraz pracujesz i co w nim widzisz?
   ```

3. **Porównaj z czatem.** Odpowiedź wygląda jak w Claude Czat – ale
   zawiera realną ścieżkę na dysku i listę plików, których nikt nie
   wgrywał.
4. **Uporządkuj sobie trzy narzędzia** jednym zdaniem każde: Czat =
   rozmowa w przeglądarce; Cowork = cel + praca w tle, klikane; Claude
   Code = to samo, bezpośrednio na plikach, w terminalu.

**Sprawdź:**

- [ ] potrafisz powiedzieć, czym Claude Code różni się od czatu w jednym
      zdaniu („pracuje na plikach na dysku, nie na załącznikach")
- [ ] wiesz, że Claude Code **pyta o zgodę** przed zmianą pliku – tak
      samo jak tryb Manual w Cowork i wtyczce Chrome

## Na co zwrócić uwagę

- **Nie musisz umieć programować.** Czarne okno terminala to tylko wygląd.
- Skoro Claude Code ma dostęp do plików, w Bloku D i Dniu 2 pracujecie na
  **fikcyjnych kopiach**, nigdy na oryginalnych danych z ERP.
