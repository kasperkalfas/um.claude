# Zadanie 7: Pierwszy kontakt z terminalem Claude Code

Ćwiczenie do szkolenia „Wykorzystanie systemu AI Claude we współpracy z
Excel, PowerPoint oraz automatyzacja zadań" (Urząd Miejski w Opolu, Dzień 1,
**Blok D, 60 min: Claude Code – pierwszy kontakt**).

**Cel:** oswoić się z oknem terminala/aplikacji Claude Code – zobaczyć, że
mimo innego wyglądu, rozmawia się z nim dokładnie tak samo jak z Claude
Czat.
**Poziom:** podstawowy
**Czas:** ok. 5 minut

> Kontekst teoretyczny (czym jest Claude Code) macie już w
> [zadaniu 2](02-czym-jest-claude-code.md), a instalację – w
> [zadaniu 6](06-instalacja-claude-code-cli.md). To zadanie jest pierwszym
> praktycznym kontaktem na żywo, prowadzonym przez prowadzącego.

## Materiały

- Claude Code uruchomiony przez prowadzącego na ekranie (demo na żywo) –
  na tym etapie nie każdy musi mieć zainstalowane u siebie.
- Folder startowy `../materialy/test-claude-code/` **skopiowany na Pulpit**
  (opis zawartości i klucz odpowiedzi: `../materialy/test-claude-code/README.md`).
  Ten sam folder służy do wszystkich zadań 7–15 – bez resetowania między
  nimi.

## Kroki

1. Prowadzący otwiera Claude Code w pustym, testowym folderze i pokazuje
   ekran: to samo pole do wpisywania wiadomości, co w Claude Czat – tylko
   w oknie terminala/aplikacji zamiast przeglądarki.
2. Wpisujecie wspólnie pierwszą wiadomość, po polsku, bez żadnej
   „programistycznej" składni, np.:
   *„Cześć! Czy widzisz, w jakim folderze teraz pracujesz?"*
3. Zwróćcie uwagę na odpowiedź – Claude Code odpowiada zdaniem, tak jak w
   czacie, tylko dodatkowo **wie, w jakim realnym miejscu na dysku się
   znajduje**.
4. Zadajcie drugie pytanie, czysto konwersacyjne, np.: *„Wytłumacz w
   dwóch zdaniach, do czego może mi się przydać taki asystent w pracy z
   plikami."*

## Na co zwrócić uwagę

- To wciąż jest **rozmowa w naturalnym języku** – nie musisz znać żadnych
  komend ani składni programistycznej.
- Jedyna nowość na tym etapie: Claude Code „siedzi" w konkretnym folderze
  na dysku, a nie w oderwanej rozmowie w przeglądarce.
- Czarne okno terminala może wyglądać onieśmielająco – to tylko wygląd,
  nie zmienia sposobu, w jaki się z nim rozmawia.
