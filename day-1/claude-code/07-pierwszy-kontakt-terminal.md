# Zadanie 7: Pierwszy kontakt z terminalem Claude Code

Ćwiczenie do szkolenia „Wykorzystanie systemu AI Claude we współpracy z
Excel, PowerPoint oraz automatyzacja zadań" (Urząd Miejski w Opolu, Dzień 1,
**Blok D, 60 min: Claude Code – pierwszy kontakt**).

**Cel:** zobaczyć, że z Claude Code rozmawia się dokładnie tak samo jak
z Claude Czat – tylko okno wygląda inaczej.
**Poziom:** podstawowy
**Czas:** ok. 5 minut

## Materiały

- Claude Code uruchomiony w `C:\Szkolenie\dzien-1\praca\test-claude-code`
  (podfolder skopiowanych materiałów `../claude-code-cli/materialy/`; klucz
  odpowiedzi w README tego folderu). Ten sam folder służy do zadań 7–15, bez resetowania.
- Na tym etapie wystarczy ekran prowadzącego – nie każdy musi mieć
  zainstalowane u siebie.

## Kroki

1. Prowadzący pokazuje okno: to samo pole do wpisywania co w Claude Czat,
   tylko w terminalu.
2. Pierwsza wiadomość, po polsku, bez żadnej składni:

   ```
   Cześć! Czy widzisz, w jakim folderze teraz pracujesz?
   ```

3. **Sprawdź:** odpowiedź to zwykłe zdanie, ale zawiera **realną ścieżkę**
   na dysku (`...\praca\test-claude-code`).
4. Drugie pytanie, czysto konwersacyjne:

   ```
   Wytłumacz w dwóch zdaniach, do czego może mi się przydać taki
   asystent w pracy z plikami.
   ```

## Na co zwrócić uwagę

- To wciąż rozmowa w naturalnym języku – żadnych komend do zapamiętania.
- Jedyna nowość: Claude Code „siedzi" w konkretnym folderze na dysku.
- Czarne okno to tylko wygląd.
